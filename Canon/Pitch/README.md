# Core Message

Project Ascension is built around one foundational principle:

```text
THE STORY
DOES NOT CONTROL
THE SIMULATION.

THE SIMULATION
PRODUCES
THE STORY.
```

Traditional games commonly build:

```text
WORLD
AROUND
PLAYER CONTENT.
```

Project Ascension attempts to build:

```text
A PERSISTENT WORLD

IN WHICH

CHARACTERS

SYSTEMS

RELATIONSHIPS

RESOURCES

INFRASTRUCTURE

INFORMATION

AND CONSEQUENCES

CONTINUE TO EXIST

WITH OR WITHOUT
THE PLAYER.
```

# Pitch Philosophy

Project Ascension should not primarily be sold as:

```text
more NPC dialogue

bigger maps

more quests

procedural content

AI characters.
```

Those may become:

```text
capabilities.
```

But the core vision is:

```text
CONTINUITY

CAUSALITY

AUTONOMY

MEMORY

TIME

CONSEQUENCE

EMERGENT HISTORY.
```

---

# Central Promise

The defining player experience should eventually be:

```text
"I left this place.

Life continued.

Now I have returned

and I want to know
what happened
while I was gone."
```

The answer should arise from:

```text
WHAT ACTUALLY HAPPENED
IN THE SIMULATION.
```

Not merely:

```text
WHAT A SCRIPT
DECIDED TO SAY
HAPPENED.
```
