# 4. Recovery Capacity

Project Ascension defines:

**Recovery Capacity**

> The available human, technical, logistical, financial, institutional, material, and temporal resources that can be used to restore degraded systems after disruption.

Status:

    CANONICAL.

Recovery capacity includes:

- skilled personnel,
- replacement equipment,
- spare parts,
- fuel,
- transport,
- emergency funding,
- inventory,
- compute,
- communications,
- institutional authority,
- political attention,
- public cooperation,
- time.

# 5. Recovery Rate

Project Ascension defines:

**Recovery Rate**

> The rate at which a system, region, or institution can remove accumulated recovery debt and restore lost resilience, reliability, and operational margin.

Status:

    CANONICAL.

---

# 6. Degradation Rate

Project Ascension defines:

**Degradation Rate**

> The rate at which disruption, deferred maintenance, resource depletion, staffing loss, security incidents, infrastructure wear, institutional friction, and secondary consequences reduce system reliability or resilience.

Status:

    CANONICAL.
