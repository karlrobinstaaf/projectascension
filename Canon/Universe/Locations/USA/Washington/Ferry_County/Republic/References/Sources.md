# 1. Purpose

This document records the external geographic and visual reference material used to construct Republic, Washington inside Project Ascension.

The objective is not merely visual inspiration.

The objective is geographic continuity.

> **Reality provides the physical baseline. Project Ascension records what happens to it.**

Reference material should allow the project to reconstruct the recognizable physical structure of Republic before fictional future changes are applied.

---

# 2. Geographic Reference Standard

Where reliable source material exists, Project Ascension should preserve the real:

- terrain
- mountains
- valleys
- roads
- streets
- intersections
- waterways
- building footprints
- major structures
- public infrastructure
- settlement pattern
- distances
- regional connections

The desired result is:

> **A player familiar with the real location should retain useful geographic intuition inside Project Ascension.**

# 28. Reference vs World Truth

A reference image may show:

```text
A GAS
STATION.
```

That proves only that the gas station existed when the reference was captured.

It does not establish:

```text
THE GAS
STATION
EXISTS

IN

PROJECT ASCENSION
GAME YEAR.
```

That requires World State.

---

# 29. Geographic Canon vs World State

This distinction must remain explicit.

```text
GEOGRAPHIC CANON

Where things are
and historically were.

WORLD STATE

What currently exists,
works, changed or failed.
```

---

# 30. Geographic Canon vs Player Knowledge

Likewise:

```text
GEOGRAPHIC CANON

SR-21 exists
south of Republic.


WORLD STATE

The road is currently
physically passable.


INFORMATION

Someone reports
the road is blocked.


PLAYER KNOWLEDGE

The group has heard
that report.


PLAYER BELIEF

The road is unsafe.
```

These are different states.
