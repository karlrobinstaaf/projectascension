# 1. Purpose

Republic, Washington is the initial geographic anchor for the first playable Project Ascension Vertical Slice.

Unlike a conventional fictional game location, Republic is built from a real place.

The foundational rule is:

> **Reality provides the geography. Project Ascension provides what happens there.**

The physical world should therefore remain recognizably connected to the real Republic even after fictional history begins changing it.

---

# 2. Geographic Canon Principle

Project Ascension treats real-world geography as the baseline World State.

Public and historically relevant people may be handled separately where necessary.

# 8. Location

Republic is located in Ferry County in northeastern Washington State.

It functions as the county seat of Ferry County.

The community is situated in a mountainous, heavily forested region with comparatively low population density and significant distances between larger population centers.

This geographic position makes Republic suitable for Project Ascension because isolation can emerge naturally from changes to:

- transportation
- communications
- electrical infrastructure
- weather
- fuel availability
- emergency services

without requiring the town itself to be artificially isolated.

# 13. State Route 20

State Route 20 provides an important east-west regional connection through northeastern Washington.

For Project Ascension, its real:

- alignment
- intersections
- passes
- distances
- surrounding terrain

should be preserved wherever practical.

Future World State may alter its condition.

---

# 14. State Route 21

State Route 21 provides an important north-south connection through Ferry County.

For the opening Vertical Slice, this route may become psychologically important because movement south can represent potential access to:

- larger communities
- infrastructure
- communications
- information
- wider transportation networks

However:

> **South is geography, not an objective marker.**

Players remain free to travel in any physically possible direction.

---

# 15. Roads Are World State

The existence of a road and the current usability of a road are different states.

```text
MAP:
Road exists.

WORLD STATE:
Unknown current condition.
```

A road may be:

- open
- congested
- blocked
- damaged
- controlled
- snow-covered
- abandoned
- partially accessible

The map does not automatically know its current condition.

---

# 16. Local Streets

Republic's actual street structure should be used as the foundation for local movement.

Players who know the real town should recognize its underlying layout.

This supports a core Project Ascension ambition:

> **A player who has been somewhere in reality should retain useful geographic intuition when visiting the same place in Project Ascension.**

# 20. Historical Foundation

Republic developed historically through mining and the economic activity surrounding the region.

Forestry and other regional industries also form part of the wider economic and cultural context.

This history matters because physical environments retain traces of earlier economic periods.

Possible traces include:

- older commercial buildings
- industrial remnants
- altered land
- transportation infrastructure
- historic structures
- family histories
- local institutions

These should be grounded in real history before fictional additions are made.

# 47. Reality as Hidden Depth

The Game Master does not need to explain every geographic fact.

Reality itself provides enormous latent detail.

This reduces the need to invent:

- every road
- every hill
- every building
- every historical layer

Project Ascension can instead ask:

> **What has happened to this real place since our timeline began to diverge?**

---

# 50. Closing Principle

Project Ascension does not need to invent America.

America already exists.

Its roads already lead somewhere.

Its towns already have histories.

Its buildings already stand on particular streets.

Its mountains already determine which directions are easy and which are difficult.

Its communities already grew for reasons.

That reality becomes the foundation.

Project Ascension adds time.

It adds Characters.

It adds Seeds.

It adds decisions.

It adds consequences.

And eventually, the players themselves add history.

> **Reality provides the place. Simulation provides the change. Players provide the history.**
