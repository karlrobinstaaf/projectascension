> *"Personality does not decide what a character will do. It changes what feels natural, difficult, desirable, frightening, acceptable, or unthinkable to them."*

---

# Purpose

The Personality and Values system defines why different characters in Project Ascension behave differently even when they face similar circumstances.

Two characters may possess:

```text
the same information

the same resources

the same capability

the same opportunity

the same external pressure
```

and still make:

```text
DIFFERENT DECISIONS.
```

Those differences should emerge from:

```text
Personality

Temperament

Values

Preferences

Aversions

Risk Disposition

Social Orientation

Life Experience

Relationships

Self-Concept

Moral Boundaries.
```

The purpose is not to create:

```text
PERSONALITY TYPES
THAT SCRIPT BEHAVIOR.
```

It is to create:

```text
CONSISTENT INDIVIDUAL
BEHAVIORAL PRESSURES.
```

---

# Core Principle

Personality should influence:

```text
HOW A CHARACTER
TENDS TO RESPOND.
```

It should not dictate:

```text
WHAT A CHARACTER
MUST ALWAYS DO.
```

Therefore:

```text
PERSONALITY
≠
SCRIPT.
```

---

# Personality Is Not Destiny

A cautious character may:

```text
take enormous risk
```

when:

```text
their child is threatened.
```

A generous character may:

```text
refuse assistance
```

when:

```text

```

A loyal character may:

```text

```


# Behavioral Tendency

Personality should be interpreted as:

```text
PROBABILITY PRESSURE
```

rather than:

```text
ABSOLUTE RULE.
```


```text

```

# Strong Aversion



```text
HARD BOUNDARY
```

```text
RIGID.
```


