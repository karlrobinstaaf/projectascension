# Test Purpose

This test validates whether a persistent character located far from the player can:

```text
receive information

interpret local conditions

make an autonomous decision

change a professional Plan

redirect resources

communicate that decision

cause logistics systems to react

change regional supply state

create downstream infrastructure pressure

and

eventually affect
the player's local environment
```

without:

```text
PLAYER PROXIMITY

PLAYER ACTIVATION

TELEPATHIC INFORMATION

INSTANT TRANSPORT

SCRIPTED WORLD MANIPULATION

OR

NARRATIVE TELEPORTATION.
```

The test directly validates:

```text
CAUSAL PROXIMITY
CAN MATTER MORE
THAN PHYSICAL PROXIMITY.
```
