# Test Purpose

This test validates whether Project Ascension can safely demote a fully simulated character from:

```text
R4 — IMMEDIATE
```

through:

```text
R3
R2
```

to:

```text
R1 — BACKGROUND
```

without losing the meaningful consequences of high-resolution interaction.

The system must prove that it can discard:

```text
temporary detail
```

while preserving:

```text
persistent consequence.
```

The central compression problem is:

```text
HIGH-RESOLUTION EXPERIENCE
↓
MEANING EXTRACTION
↓
PERSISTENT STATE CHANGE
↓
LOW-RESOLUTION CHARACTER.
```
