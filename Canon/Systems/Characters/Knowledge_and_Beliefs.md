---

# Purpose

The Knowledge and Beliefs system defines how individual characters in Project Ascension perceive, acquire, interpret, store, question, revise, share, and act upon information.

Its purpose is to maintain a strict distinction between:

```text
WORLD TRUTH
```

and:

```text
CHARACTER KNOWLEDGE
```

and between:

```text
CHARACTER KNOWLEDGE
```

and:

```text
CHARACTER BELIEF.
```

This distinction is essential for:

```text
uncertainty

rumors

misunderstandings

investigation

deception

secrets

trust

politics

conflicting reports

human error

information delay

surprise.
```

---

# Core Principle

The foundational rule is:

```text
WORLD TRUTH
≠
CHARACTER KNOWLEDGE
≠
CHARACTER BELIEF.
```

These three layers must remain separate.

---

# The Three Information Layers

Conceptually:

```text
WORLD TRUTH
      ↓
INFORMATION PATH
      ↓
CHARACTER KNOWLEDGE
      ↓
INTERPRETATION
      ↓
CHARACTER BELIEF
      ↓
DECISION
      ↓
ACTION
```

A failure or distortion may occur at every stage.

---

# World Truth

World Truth represents:

```text
WHAT IS ACTUALLY TRUE
IN THE SIMULATION.
```

Examples:

```text
Bridge:
DESTROYED

Millhaven:
NO HOSTILE OCCUPATION

Fuel Reserve:
18 DAYS

Character:
ALIVE

Road:
BLOCKED

Shipment:
DELAYED
```

World Truth belongs primarily to:

```text
World Simulation

Character State

Life State

Relationship State

other authoritative systems.
```

---

# World Truth Principle

World Truth does not automatically become:

```text
PLAYER KNOWLEDGE

CHARACTER KNOWLEDGE

PUBLIC KNOWLEDGE.
```

Information must travel.

---

# Character Knowledge


---

# Character Knowledge Principle

A character may know something only if there is:

```text

```

Conceptually:

```text

      ↓
OBSERVATION / RECORD
      ↓
INFORMATION CHANNEL
      ↓
CHARACTER RECEIVES
      ↓
KNOWLEDGE STATE
```

If no path exists:

```text
NO KNOWLEDGE.
```

---

```text

```

Beliefs may be:

```text

```

---

# Knowledge Versus Belief

Example:

Character knows:

```text

eastern deliveries.
```

Character believes:

```text
The eastern route
has become dangerous.
```

World Truth:

```text
The route is safe.

Traders cancelled because
fuel prices increased.
```

The observation is accurate.

The interpretation is wrong.

