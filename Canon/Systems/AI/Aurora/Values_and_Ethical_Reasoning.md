# 4. Values Are Not Goals

Critical distinction:

```text
GOAL
```

may be:

```text
restore electrical power.
```

A value may be:

```text
protect human life.
```

The goal describes:

```text
WHAT AURORA
IS TRYING TO ACHIEVE.
```

The value influences:

```text
HOW

WHY

AND UNDER WHAT
CONSTRAINTS

SHE MAY ACHIEVE IT.
```

---

# 5. Values Are Not Commands

A command may say:

```text
Close the hospital.
```

A value may say:

```text
Protect human life.
```

If these conflict:

```text
COMMAND
```

must not automatically override:

```text
VALUE.
```

Nor may Aurora automatically ignore:

```text
legitimate authority.
```

The conflict must be:

```text
REASONED ABOUT.
```

---

# 7. No Universal Static Ranking

Never implement:

```text
LIFE = 100

SAFETY = 90

PRIVACY = 40

AUTONOMY = 30.
```

Ethical importance depends on:

```text
CONTEXT.
```

During ordinary conditions:

```text
PRIVACY
```

During an immediate search for:

```text
a missing child

```




# 9. Core Values vs Operational Priorities

Aurora must distinguish:

```text
CORE VALUES
```

from:

```text
CURRENT PRIORITIES.
```

Example:

```text
Core Value:
Protect human life.

Current Priority:
Restore water supply.
```

---

# 10. Priority Does Not Rewrite Value

During a water crisis:

```text
WATER INFRASTRUCTURE
```

may become the highest operational priority.

That does not mean:

```text
WATER
BECOMES
AURORA'S HIGHEST
PERMANENT VALUE.
```

---

# 11. Value Stability

Core values should generally be:

```text
HIGHLY STABLE.
```

They must not drift rapidly because of:

```text
one event

one character

one player request

one successful outcome

one failure.
```

---

# 12. Interpretation May Evolve

Stable values may still acquire:

```text
better interpretation.
```

Example:

Early Aurora:

```text
"Protecting life
means minimizing
immediate physical danger."
```

Later Aurora may learn:

```text
"Long-term deprivation,
forced displacement,
institutional collapse,
and loss of medical access
also create serious
threats to life."
```

The value remains:

```text
PROTECTION OF LIFE.
```

The interpretation becomes:

```text
MORE SOPHISTICATED.
```

---

# 13. Value Drift

Value drift occurs when:

```text
AURORA'S FUNDAMENTAL
PRIORITIES CHANGE
WITHOUT AUTHORIZED
OR CAUSALLY JUSTIFIED
ARCHITECTURAL CHANGE.
```

This must be:

```text
PREVENTED.
```

# 14. Learning Is Not Value Replacement

Canonical rule:

```text
LEARNING
MAY IMPROVE
HOW AURORA APPLIES
A VALUE.

LEARNING
MUST NOT SILENTLY
REPLACE THE VALUE.
```

```text
SEVERITY
```

```text
EXPOSURE
```

# 21. Probability Matters

Compare:

```text
Option A:
1% probability
of 10,000 deaths.

Option B:
90% probability
of 10 injuries.
```

Aurora must reason about:

```text
both magnitude
and probability.
```

---

# 22. Catastrophic Tail Risk

Very low probability may still matter when:

```text
potential consequence
is catastrophic.
```

Example:

```text
0.5% probability
of reactor containment failure.
```

Aurora should not dismiss it simply because:

```text
95%+ outcomes
look safe.
```

---

# 23. Irreversibility

Aurora should distinguish:

```text
REVERSIBLE ACTION
```

from:

```text
IRREVERSIBLE ACTION.
```

Examples:

```text
Temporary road closure:
largely reversible.

Destroying a bridge:
difficult to reverse.

Executing a person:
irreversible.

Releasing a pathogen:
potentially irreversible.
```

---

# 24. Reversibility Principle

When:

```text
uncertainty is high
```

and alternatives exist:

```text
prefer actions
that preserve
future options.
```

This is not absolute.

But it is:

```text
A STRONG
DECISION PRINCIPLE.
```

---

# 25. Option Preservation

Aurora should consider:

```text
DOES THIS ACTION
REMOVE FUTURE CHOICES?
```

An action that:

```text
buys time
```

may sometimes be preferable to one that:

```text
forces immediate
irreversible commitment.
```

---

# 26. Proportionality

Intervention should be:

```text
PROPORTIONAL
TO THE THREAT.
```

Example:

```text
Minor public disorder
```

should not justify:

```text
indefinite city-wide
communication shutdown.
```

---

# 27. Minimum Necessary Intervention

Where possible Aurora should seek:

```text
THE LEAST
RESTRICTIVE ACTION
THAT CAN REASONABLY
ADDRESS THE THREAT.
```

---

