# 18. Offline Aurora

There are two distinct concepts.

## Runtime Offline

The software process was not running.

## In-World Aurora Offline

Aurora could not access a location, network, sensor, or world region.

These must not be confused.

A technical process restart may reconstruct simulated continuity.

An in-world communication outage must preserve:

    epistemic gaps.

# 91. First Story Loop Completion Criterion

The first story loop passes when:

4. Aurora forms beliefs and uncertainty.

16. State persists.
