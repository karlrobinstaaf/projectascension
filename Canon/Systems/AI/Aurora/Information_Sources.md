# 1. Purpose

This document defines the canonical information-source architecture for:

```text
AURORA.
```

It answers:

```text
WHERE CAN
AURORA'S INFORMATION
COME FROM?
```

And:

```text
HOW DOES INFORMATION
MOVE FROM THE WORLD

INTO

AURORA'S KNOWLEDGE SYSTEM?
```

Aurora must never obtain information merely because:

```text
THE SIMULATION
CONTAINS IT.
```

Information must originate through:

```text
A SOURCE

AN OBSERVATION

A RECORD

A MESSAGE

A SENSOR

A CHARACTER

AN ORGANIZATION

AN AUTHORIZED SYSTEM

OR

A DEFENSIBLE INFERENCE.
```

---

# 2. Foundational Source Principle

The canonical rule is:

```text
WORLD TRUTH
↓
DOES NOT AUTOMATICALLY BECOME
↓
AURORA INFORMATION.
```

Instead:

```text
WORLD EVENT
↓
OBSERVATION
↓
SOURCE
↓
TRANSMISSION
↓
ACCESS
↓
RECEPTION
↓
INTERPRETATION
↓
AURORA STATE.
```

Every meaningful step matters.

---

# 3. Source Is Not Truth

A source provides:

```text
INFORMATION.
```

A source does not provide:

```text
GUARANTEED TRUTH.
```

A source may be:

```text
correct

incorrect

outdated

incomplete

biased

misconfigured

deceived

compromised

misinterpreted.
```

Therefore:

```text
SOURCE
≠
TRUTH.
```



```text

```

to determine:

```text

what they really believe

```

# 39. Source Lineage

Source lineage answers:

```text
WHERE DID THIS
INFORMATION ORIGINALLY
COME FROM?
```

Example:

```text
Current Reporter:
Regional News Network

Original Source:
County Sheriff

Original Observation:
Deputy at location.
```

---

# 40. Why Lineage Matters

Without lineage Aurora may interpret:

```text
ten repeated reports
```

as:

```text
ten independent confirmations.
```

When in reality:

```text
all ten
derive from one witness.
```

This creates:

```text
FALSE CORROBORATION.
```

---

# 41. Independent Sources

Sources are independent when:

```text
their information
did not derive from
the same underlying observation
or communication chain.
```

Example:

```text
road camera

police patrol

satellite observation
```

may provide:

```text
three independent observations.
```

---

# 42. Dependent Sources

Example:

```text

social post quoting news.
```

```text

```

## AURORA-SOURCE-INV-002 — Source Is Not Truth

```text
No source is automatically
equivalent to World Truth.
```

---

## AURORA-SOURCE-INV-003 — Character Privacy

```text
Characters may only provide
information through valid
observable or communicative paths.
```

---

## AURORA-SOURCE-INV-004 — Player Is a Source

```text
Player reports are information,
not automatic truth.
```

---

## AURORA-SOURCE-INV-005 — Source Lineage

```text
Repeated transmission of one claim
must not become false
independent corroboration.
```

---

## AURORA-SOURCE-INV-006 — Finite Latency

```text
Information must take
a valid causal path
from source to Aurora.
```

---

## AURORA-SOURCE-INV-007 — Access Required

```text
A source being reachable
does not imply Aurora
is authorized to read it.
```

---

## AURORA-SOURCE-INV-008 — Coverage Is Limited

```text
Information from a source
must not be generalized
beyond its valid coverage
without inference.
```

---

## AURORA-SOURCE-INV-009 — Source Silence Is Ambiguous

```text
No report does not
automatically mean
no event.
```

---

## AURORA-SOURCE-INV-010 — Availability Changes

```text
Source availability
must be dynamic.
```

---

## AURORA-SOURCE-INV-011 — Authentication Is Separate

```text
Authenticating the source
does not confirm the claim.
```

---

## AURORA-SOURCE-INV-012 — Historical Data Is Historical

```text
Late-arriving historical data
must not create
retroactive Aurora awareness.
```

---

## AURORA-SOURCE-INV-013 — Human State Is Hidden

```text
Aurora must never inspect
private Character State
to verify a human report.
```

---

## AURORA-SOURCE-INV-014 — Domain Reliability

```text
Source reliability may differ
by information domain.
```

---

## AURORA-SOURCE-INV-015 — Aggregation Is Not Independence

```text
An aggregator repeating
many dependent reports
does not create
independent evidence.
```

---

## AURORA-SOURCE-INV-016 — Transmission May Fail

```text
A source knowing something
does not mean Aurora
will receive it.
```

---

## AURORA-SOURCE-INV-017 — Integrity Matters

```text
Information may be altered
between source and Aurora.
```

---

## AURORA-SOURCE-INV-018 — Blind Spots Are Explicit

```text
Lack of source coverage
must create uncertainty,
not assumed normality.
```

---

## AURORA-SOURCE-INV-019 — Source History Persists

```text
Meaningful source behavior
must remain available
for future trust evaluation.
```

---

## AURORA-SOURCE-INV-020 — No Retroactive Source Path

```text
The engine must never invent
an earlier information path
to justify Aurora
knowing something sooner.
```
