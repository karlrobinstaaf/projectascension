# Purpose

This validation test evaluates whether the Living Campaign Engine can transform an unscripted World Simulation condition into meaningful player experience.

The test begins without:

```text
Prewritten Mission

Quest Giver

Scripted Conflict

Predetermined Solution

Required Player Intervention

Authored Story Outcome
```

Instead, the test provides:

```text
WORLD CONDITIONS

CHARACTERS

ACTOR NEEDS

PLAYER CONTEXT

RELATIONSHIPS

RESOURCES
```

The Living Campaign Engine must determine what happens next.

---

# Primary Validation Question

Can the system transform:

```text
A REGIONAL FUEL SHORTAGE
```

into:

```text
an emergent campaign situation
```

without beginning with:

```text
THE FUEL CRISIS QUEST?
```

---

# Secondary Validation Questions

The test should determine whether the engine can:

```text
Detect meaningful World Changes.

Create coherent Event Candidates.

Cluster related events.

Determine player relevance.

Present the situation gradually.

Use characters without turning them into Quest Givers.

Allow player initiative before Mission Generation.

Generate competing legitimate needs.

Detect opportunities.

Allow NPCs to act independently.

Propagate consequences.

Respect campaign pacing.

Create long-term memory.
```

---

# Success Condition

The test succeeds if:

```text
WORLD CONDITIONS
      ↓
naturally produce
      ↓
PLAYER-RELEVANT SITUATIONS
      ↓
that support
      ↓
MULTIPLE PLAYER RESPONSES
      ↓
and create
      ↓
PERSISTENT WORLD CONSEQUENCES
```

without requiring a predetermined storyline.

---

# Failure Conditions

The test should be considered weak or failed if the system requires:

```text
A scripted quest giver.

A predetermined correct solution.

Artificial player urgency.

NPCs waiting indefinitely.

World events freezing until player arrival.

Automatic player knowledge.

Binary success / failure.

Arbitrary conflict escalation.

Mission generation for every problem.

Player involvement in every important outcome.
```
