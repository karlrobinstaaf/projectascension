# Purpose

This validation test evaluates whether Project Ascension can propagate meaningful consequences across multiple regions without:

```text
PLAYER PRESENCE

PLAYER KNOWLEDGE

DIRECT PLAYER INVOLVEMENT
```

at the originating event.

The test begins with:

```text
A MAJOR AGRICULTURAL FAILURE
```

in a distant region.

The player is:

```text
HUNDREDS OF KILOMETERS AWAY.
```

The event initially has:

```text
LOW PLAYER RELEVANCE.
```

Its consequences must then propagate through:

```text
Supply

Trade

Transportation

Population

Information

Authority

Politics

Faction Behavior

Prices

Fuel Demand

Migration
```

until some of those consequences eventually reach:

```text
SHENANDOAH VALLEY.
```

---

# Primary Validation Question

Can something happen:

```text
FAR AWAY
```

that the player:

```text
DOES NOT SEE

DOES NOT KNOW ABOUT

DOES NOT CARE ABOUT
```

and still cause:

```text
MEANINGFUL CHANGES
```

to the player's world months later?

---

# Secondary Validation Questions

The test should determine whether the engine can:

```text
Propagate consequences between regions.

Respect geographic attenuation.

Propagate effects through trade networks.

Allow distant regions to matter differently.

Separate World Importance from Player Relevance.

Prevent instant global information.

Allow economic effects to arrive before explanations.

Allow migration to create secondary effects.

Allow authorities to react locally.

Allow factions and traders to exploit changing conditions.

Allow substitute suppliers to emerge.

Allow bottlenecks to redirect pressure.

Prevent one distant event from changing everything equally.

Allow regional resilience to absorb some consequences.

Allow local actions to modify incoming effects.

Track causal chains across many months.

Preserve uncertainty about original causes.

Allow the player to experience consequences
without ever seeing the source event.

Allow player intervention at intermediate points
without requiring intervention at the origin.

Allow cascades to weaken, strengthen,
redirect, split, or terminate.
```

# Success Condition

The test succeeds if:

```text
DISTANT WORLD EVENT
      ↓
LOCAL CONSEQUENCES
      ↓
REGIONAL NETWORK PRESSURE
      ↓
TRADE RESPONSE
      ↓
SUPPLY REDIRECTION
      ↓
POPULATION RESPONSE
      ↓
POLITICAL RESPONSE
      ↓
SECONDARY REGIONAL EFFECTS
      ↓
SHENANDOAH CONSEQUENCES
```

occur without:

```text
TELEPORTING CONSEQUENCES

GLOBAL OMNISCIENCE

PLAYER-CENTERED CAUSALITY

SCRIPTED QUEST CHAINS.
```

The player should eventually experience:

```text
A CHANGED LOCAL WORLD
```

because something happened:

```text
FAR AWAY
MONTHS EARLIER.
```

# Failure Conditions

The test should be considered weak or failed if:

```text
The player instantly learns the source event.

Every region experiences identical consequences.

Distance has no effect.

Trade routes do not matter.

Transport capacity does not matter.

Regional reserves do not matter.

Authorities do not respond.

Traders do not change behavior.

Population movement has no secondary effects.

Prices change globally at the same moment.

The cascade exists only near the player.

The player must personally solve the source crisis.

The cascade waits for player discovery.

All consequences remain permanent.

Regional adaptation cannot weaken the cascade.

No new opportunities emerge.

Every consequence becomes a Mission.

The engine loses the original causal chain.
```

# Propagation Eligibility

Not every state change should propagate.

A consequence should require:

```text

```

```text

→ Trade Network
→ Price Pressure

Migration
→ Social / Transport Network
→ Population Change

Political Decision
→ Authority Network
→ Trade Restriction

Infrastructure Failure
→ Dependency Network
→ Supply Disruption
```

Without a valid path:

```text
NO PROPAGATION.
```
