PROJECT ASCENSION

PROJECT MANIFEST

Project Ascension is not a prediction.

It is a conversation about tomorrow.

•

Questions are more valuable than answers.

•

Build consequences before content.

•

Respect the player's intelligence.

•

Humanity is the story.
Technology is the catalyst.

•

Begin with the familiar.
Challenge it gradually.

•

The world should feel like looking through a window into one possible future.

•

We are not building a game about AI.

We are building a game about humanity encountering something it cannot fully understand.

•

If players continue talking after the adventure ends...

Project Ascension is still being played.
